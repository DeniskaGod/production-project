# Админ Панель - Быстрый Старт

## Что было сделано?

Создана **красивая и функциональная админ-панель** с полной поддержкой управления пользователями и статьями.

## Как использовать?

### Шаг 1: Откройте админ-панель

Перейдите по адресу: `http://localhost:3000/admin`

### Шаг 2: Просмотрите статистику

В верхней части видны 4 ключевые метрики:

- Всего пользователей
- Активных статей
- Всего комментариев
- Средний рейтинг

### Шаг 3: Переключайтесь между вкладками

- ** Пользователи** - управление пользователями
- ** Статьи** - управление статьями

### Шаг 4: Используйте поиск

Ищите по:

- Имени или email пользователя
- Названию или автору статьи

### Шаг 5: Выполняйте действия

- **Редактировать** - отредактировать запись (функция готова для подключения)
- **Удалить** - удалить запись (работает с Redux состоянием)

## Интеграция с API

Чтобы подключить реальный API:

```typescript
// В компоненте AdminPanelPage.tsx
useEffect(() => {
  // Вместо mock данных
  dispatch(fetchAdminUsers()); // Async thunk для загрузки
}, [dispatch]);
```

Пример создания async thunk:

```typescript
export const fetchAdminUsers = createAsyncThunk(
  "adminPanel/fetchUsers",
  async (_, { rejectWithValue }) => {
    const response = await api.get("/api/admin/users");
    return response.data;
  },
);
```

## Проверка прав доступа

Администратор должен иметь роль `ADMIN`:

```tsx
const authData = useSelector(selectUserAuthData);
const isAdmin = authData?.roles?.includes("ADMIN");

if (!isAdmin) {
  return <Navigate to="/" replace />;
}
```

## FAQ

**Q: Как изменить цвета?**  
A: Отредактируйте CSS переменные в вашей теме, используемой в проекте.

**Q: Как добавить новый язык?**  
A: Создайте файл `public/locales/{lang}/admin.json` с переводами.

**Q: Как подключить API?**  
A: Создайте async thunk в Redux и используйте его в useEffect.
