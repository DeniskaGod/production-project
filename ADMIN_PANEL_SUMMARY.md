## 🚀 Функциональность

### Панель статистики
```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│      4      │      3      │     128     │     4.8     │
│ Пользователи│   Статьи    │ Комментарии │   Рейтинг   │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

### Управление пользователями
- Список всех пользователей с ролями
- Фильтрация по имени/email
- Удаление пользователей
- Цветовые теги для ролей:
  - 🔴 ADMIN (красный)
  - 🟠 MANAGER (оранжевый)
  - 🟢 USER (зеленый)
  - 🟣 OWNER (фиолетовый)

### Управление статьями
- Список всех статей
- Фильтрация по названию/автору
- Просмотр статусов:
  - 🟢 Опубликована
  - 🟡 Черновик
  - ⚫ Архивирована
- Удаление статей
