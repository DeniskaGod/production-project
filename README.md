# Curs

Веб-приложение на React и TypeScript с каталогом статей, профилями пользователей, комментариями, локализацией и административной панелью.

## Возможности

- просмотр и редактирование статей;
- профили пользователей и авторизация;
- комментарии к статьям;
- переключение русского и английского языков;
- светлая и темная темы;
- административная панель для просмотра пользователей, статей и статистики.

## Технологии

- React 17 и TypeScript;
- Redux Toolkit;
- React Router;
- SCSS Modules;
- i18next;
- Webpack;
- Jest и Testing Library;
- json-server для локального API.

## Установка

Требуется Node.js и npm.

```bash
npm install
```

## Запуск

Запуск только фронтенда:

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

Запуск фронтенда вместе с локальным API:

```bash
npm run start:dev
```

Локальный API использует данные из `json-server/db.json`.

## Основные команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск dev-сервера Webpack |
| `npm run start:dev` | Запуск фронтенда и json-server |
| `npm run start:server` | Запуск только локального API |
| `npm run build:prod` | Production-сборка |
| `npm run build:analyze` | Production-сборка с анализом бандла |
| `npm run lint:check` | Проверка TypeScript/ESLint |
| `npm run stylelint:check` | Проверка SCSS |
| `npm run unit` | Запуск unit-тестов |

## Структура проекта

```text
src/
├── app/       # Инициализация приложения, провайдеры и общие стили
├── entities/  # Бизнес-сущности
├── features/  # Пользовательские сценарии
├── pages/     # Страницы приложения
├── shared/    # Общие UI-компоненты, API, типы и утилиты
└── widgets/   # Составные блоки интерфейса
```

Проект организован по принципам Feature-Sliced Design.
